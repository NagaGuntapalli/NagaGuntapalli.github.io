# Publish the refined portfolio

1. Extract `NagaGuntapalli-portfolio-classic.zip`.
2. Open <https://github.com/NagaGuntapalli/NagaGuntapalli.github.io>.
3. Select **Add file → Upload files**.
4. Upload the four website files: `index.html`, `styles.css`, `script.js`, and `README.md`.
5. GitHub will show that the files already exist and will replace them after the commit.
6. Enter the message `Refine portfolio design and add Blinq`.
7. Select **Commit changes**.
8. Wait about 1–3 minutes, then refresh <https://nagaguntapalli.github.io/> using **Ctrl+F5**.

The update preserves the existing `404.html` and `.gitignore` files.
